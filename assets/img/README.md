# Photos

Drop images here and reference them in `js/data.js` → `images`.

| Slot | Suggested file | Notes |
|---|---|---|
| `hero` | `hero-aerial.jpg` | wide aerial, ≥ 2000 px, landscape |
| `about` | `about-aerial.jpg` | ~600×460 or any 4:3 aerial/map photo |
| `featuredBefore` | `lac-pitch-before.jpg` | 4:3 |
| `featuredDuring` | `lac-pitch-during.jpg` | 4:3 |
| `featuredAfter` | `lac-pitch-after.jpg` | 4:3 |
| `sports.<id>` | `sport-cricket.jpg` etc. | ~800×450 |

Keep files under ~400 KB each (export as JPG, quality 75–80) so the page stays fast on phones.
